1. Getting Started

Getting started with SENTRA takes less than two minutes:

  1. Create an account: Register with your username, email, and password.
  2. Connect GitHub: Authorize SENTRA through the secure GitHub OAuth integration.
  3. Import a repository: Browse your public and private repositories and select one to audit.
  4. Automatic analysis: SENTRA retrieves manifests, matches CVEs, audits README completeness, and categorizes licenses.
  5. Review security posture: Inspect actionable findings and recommendations on your dashboard.

2. Connecting GitHub & Security

SENTRA requests minimal read-only permissions to inspect repository files and directory trees.

  • OAuth State Validation: Protects against Cross-Site Request Forgery during authorization handshakes.
  • Per-User Account Isolation: Each user connection is strictly bounded. Users cannot see or import another user's private repositories.
  • Token Protection: OAuth access tokens are encrypted and kept strictly on the backend; they are never sent to browser storage or exposed in URLs.
  • Revocation: You can disconnect your GitHub account at any time from your Account Profile.

4. Understanding Risk Scores

SENTRA's risk engine aggregates signals into a unified 0–100 risk score. A lower score reflects a more secure repository:

Low Risk (0 - 24)
Clean dependencies, minimal or zero known CVEs, permissive licensing.
Medium Risk (25 - 49)
Moderate vulnerabilities, weak copyleft licenses, or outdated packages.
High Risk (50 - 74)
High-severity CVEs or strong copyleft licenses requiring source disclosure.
Critical Risk (75 - 100)
Critical severity vulnerabilities with active exploits requiring immediate attention.

Note: SENTRA risk scores are informational engineering assessments based on automated checks. They do not constitute formal legal advice or standardized compliance certifications.

5. Exporting Security Assets

Every completed scan allows you to download machine-readable assets:

  • JSON Security Report — Detailed breakdown of dependencies, risk scores, CVE entries, and license findings.
  • CycloneDX 1.4 SBOM — Standardized Software Bill of Materials in JSON format, ready for supply-chain compliance workflows.
