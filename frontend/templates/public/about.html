How It Works

A direct, four-stage workflow.

From initial repository connection to verified risk remediation, SENTRA keeps every stage understandable.

01

Connect

Authorize GitHub with granular OAuth scopes and select the repositories you wish to audit.

02

Analyze

SENTRA extracts package manifests, resolves dependency trees, and cross-references vulnerability feeds.

03

Understand

Review aggregated security scores, vulnerability vectors, copyleft flags, and documentation health.

04

Secure

Take targeted remediation steps, export CycloneDX SBOMs, and ensure continuous compliance.
