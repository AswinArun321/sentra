Platform Features

Repository Security,
All in One Place.

SENTRA brings dependency analysis, vulnerability detection, license intelligence, repository health, and documentation checks into one unified platform.

Vulnerability Detection

SENTRA continuously queries authoritative databases including OSV.dev to identify known CVEs across open-source dependencies. Every finding details severity, affected version ranges, CVSS scores, and available patches to accelerate remediation without false promises of unverified zero-day detection.

Dependency Intelligence

Automated parsers traverse repository trees to identify project manifests such as requirements.txt and package.json. SENTRA extracts exact package names and versions, maps dependencies across ecosystems, and catalogs libraries directly from repository commits without requiring manual uploads.

License Compliance

Understand open-source legal obligations before deployment. SENTRA detects licenses associated with third-party components and organizes them into distinct categories: Permissive (e.g. MIT, Apache-2.0, BSD), Copyleft (e.g. GPLv3), Weak Copyleft (e.g. LGPL, MPL), and Unknown, flagging potential compliance violations.

README Health

Complete documentation accelerates onboarding and prevents deployment misconfigurations. SENTRA checks for README presence, evaluates section completeness across overview, installation, usage, and contribution guidelines, and provides ready-to-commit templates directly to GitHub.

Repository Health

Beyond individual packages, SENTRA evaluates commit recency, license presence, and maintainer activity across dependencies to flag abandoned libraries that no longer receive security updates.

Risk Intelligence Engine

Analysis signals are combined into a weighted repository risk score (Security 50%, License Compliance 25%, Maintenance 15%, Dependency Health 10%). The resulting score provides clear visibility into overall risk without falsely claiming to represent an official external standard.
