Frequently Asked Questions

Everything you need to know.

Clear answers about how SENTRA inspects repositories, detects risks, and protects your credentials.

SENTRA analyzes repository dependency manifests (such as requirements.txt, package.json, pom.xml, and go.mod), correlates third-party packages against real-time vulnerability databases, inspects open-source license compliance, and scores documentation and repository vitality.
You connect your GitHub account using OAuth. SENTRA accesses your authorized repositories via the GitHub REST API without requiring custom CI/CD runner installations or build agent configurations.
SENTRA natively inspects Python requirements.txt, Node.js package.json, Java pom.xml, and Go go.mod manifests, identifying both direct packages and their pinned version constraints.
Resolved package names and versions are automatically queried against OSV.dev and national CVE feeds, returning standardized CVSS severity ratings, vulnerability descriptions, and affected version ranges.
License intelligence classifies the licenses of every dependency in your codebase (e.g. MIT, Apache-2.0, BSD, GPL, AGPL) and alerts you to restrictive copyleft requirements that could force open-sourcing of proprietary software.
Yes. SENTRA exports comprehensive Software Bill of Materials (SBOM) in the industry-standard CycloneDX 1.4 JSON and XML formats for compliance audits and procurement review.
No. SENTRA never sees or stores your GitHub password. It communicates strictly via scoped OAuth access tokens stored securely in encrypted sessions per user.
