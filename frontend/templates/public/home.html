The Challenge

Software supply chains carry hidden risks.

Repositories rely on third-party code. Direct dependencies pull in transitive trees that code reviews rarely inspect. A single unpatched flaw or restrictive copyleft license can put production workloads and compliance at risk.

Transitive Vulnerabilities

Packages often install nested sub-dependencies with known CVEs. These flaws bypass standard pull-request reviews and lockfile checks.

License Incompatibilities

Copyleft licenses such as GPL or AGPL in utility libraries can obligate teams to release proprietary application source code.

Abandoned Packages

Packages without active maintainer commits accumulate unpatched bugs, lack security responses, and block runtime upgrades.

Capabilities

Six repository signals. One unified audit.

SENTRA evaluates your codebase across six distinct security and operational dimensions without requiring CI/CD agents.

01

Dependency Inspection

Extracts and catalogs direct and transitive packages from requirements.txt, package.json, and lockfiles across repository branches.

02

Vulnerability Detection

Queries every discovered package version against the OSV.dev open-source database to report exact CVE IDs, severity levels, and patch targets.

03

License Classification

Categorizes dependency licenses into Permissive (MIT, Apache, BSD), Copyleft (GPL, AGPL), and Unknown categories to keep your distribution compliant.

04

README Quality Audit

Audits repository documentation completeness across project description, installation instructions, usage guidelines, and license references.

05

Repository Vitality

Measures commit recency, maintainer count, and package release activity to flag unmaintained third-party dependencies early.

06

Risk Scoring & SBOM

Calculates a weighted 0-100 risk score and exports standard CycloneDX 1.4 JSON Software Bill of Materials for compliance records.
